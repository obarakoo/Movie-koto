# Findings

## Research & Discoveries
- Target tech stack: React, Vite, Tailwind CSS, Axios, React Router.
- APIs to integrate: The Movie Database (TMDB) API, OMDb API, TVMaze API.
- Project Structure: Standard React structure with folders for components, pages, hooks, utils, api.
- Provided Image: Will be used as the logo ("Movie Hub" graphical logo).

## Useful Endpoints (TMDB)
- Trending: `/trending/movie/day`
- Popular: `/movie/popular`
- Top Rated: `/movie/top_rated`
- Search: `/search/movie`
- Details: `/movie/{movie_id}`
- Videos: `/movie/{id}/videos`
- Recommendations: `/movie/{id}/recommendations`
- Person/Actor: `/person/{person_id}`, `/person/{id}/movie_credits`

## Useful Endpoints (TVMaze)
- Shows: `https://api.tvmaze.com/shows`
